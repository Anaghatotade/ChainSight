# Data dictionary

Raw M5 files live in `data/raw/` (see `DATA_SOURCE.md`). Everything in `data/processed/` and `outputs/` is generated by the pipeline.

## Raw tables
| File | Grain | Columns |
|---|---|---|
| `calendar.csv` | day | date, wm_yr_wk, weekday, wday, month, year, d (`d_1`...), event_name_1/2, event_type_1/2, snap_CA, snap_TX, snap_WI |
| `sales_train_validation` | item x store | id, item_id, dept_id, cat_id, store_id, state_id, then one column per day `d_1` ... `d_1913` (units) |
| `sell_prices` | item x store x week | store_id, item_id, wm_yr_wk, sell_price |

Hierarchy: item -> department (7) -> category (3: FOODS, HOUSEHOLD, HOBBIES); store (10) -> state (3: CA, TX, WI). A series = one item in one store ("30,490 series"). Item x state (9,147 series) is the forecasting level.

## Cleaned panel (`data/processed/`)
| File | Content |
|---|---|
| `panel.npz` | `units` int matrix [series, week] and `price` float matrix [series, week]; **NaN price = item not on sale that week** (units set to 0 and excluded from KPIs / forecasts) |
| `series.csv` | one row per item-store series: series_id, item_id, dept_id, cat_id, store_id, state_id |
| `weeks.csv` | one row per full week: week_idx (0 = week starting Saturday 2011-01-29), wm_yr_wk, week_start, month (of the middle of the week), year, snap_days_CA/TX/WI, event_days |
| `daily_store_dept.csv` | date x store x department: units, revenue (small daily aggregate) |
| `dim_date.csv` | calendar rows inside the analysis window plus week_idx |
| `m5_retail.db` | SQLite star schema built from the above (`sql/00_schema.sql`) |
| `forecast_predictions.csv.gz` | dev + test forecasts of every model per item x state x week |

## Definitions
| Term | Definition |
|---|---|
| Revenue | units x weekly sell price (list price; there is no cost or discount data) |
| On sale | the item has a price listed in that store that week |
| Zero-sales week | on-sale week with zero units (**not** necessarily a stock-out) |
| ABC class | by cumulative item revenue: A first 80%, B next 15%, C rest (share before the item decides) |
| CV | std / mean of weekly units at item x state level (stable < 0.5, variable < 1.0, erratic >= 1.0) |
| ADI / CV2 class | Syntetos-Boylan: ADI < 1.32 and CV2 < 0.49 smooth; ADI < 1.32 erratic; ADI >= 1.32 intermittent or lumpy |
| Price-cut week | price <= 90% of the previous 8-week average price |
| WAPE | sum abs(forecast - actual) / sum(actual) |
